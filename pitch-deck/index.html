Custom Engine Architecture

Engineered for Locked 60 FPS Mobile Performance

We built our proprietary PWA rendering stack from the ground up to guarantee buttery-smooth 60 FPS gameplay on real-world Android and iOS hardware.

⚡

PixiJS WebGL v8 Pipeline

Batch-rendered 2D/2.5D isometric map engine with compressed WebP texture atlases, GPU particle systems, and zero main-thread canvas blocking.

📱

Sub-16ms Frame Budget

Tested on mid-range hardware (Samsung Galaxy A-series). Eliminates SVG layout thrashing by utilizing 4 GPU perimeter panels (`translateZ(0)`) and composited opacity transforms.

🔊

Web Audio API Synthesizer

Zero-latency procedural sound generation and polyphonic positional combat audio running natively without loading bloated sound banks.

🌐

Offline-First PWA Cache

Multi-tiered Service Worker caching (v1.3.0) with immutable CDN headers. Returning players load the entire game instantly with near 0 bytes consumed.

☁️

Hybrid Supabase Sync

Instant optimistic local state for zero-latency gameplay, backed by secure Row Level Security (RLS) cloud sync for multiplayer leaderboards.

🎮

Cross-Platform Input Engine

Dual input architecture: seamless WASD + Space on PC keyboards, and automatic virtual analog joystick with clamped angle vectors on mobile touchscreens.
